## Summary

从本地实验脚本向生产级 AI 系统过渡，AI 工程师需要掌握五类 Python 工程能力：

1. Generators / lazy evaluation：流式处理大数据，降低内存峰值；
2. Context managers：管理 GPU、连接、模型状态、profiling 等资源生命周期；
3. Async programming：提升 LLM API、向量库、agent tool 等网络 I/O 工作流吞吐；
4. Dataclasses / Pydantic：结构化配置和边界输入校验；
5. Magic methods：让自定义对象兼容 Python / PyTorch 协议。
